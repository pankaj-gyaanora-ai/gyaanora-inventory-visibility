Where this number comes from

Every figure on this board is read from one published run. The board does not compute anything, so a failed overnight run leaves yesterday's numbers visible and marked stale rather than showing a wrong one.

Same engine, two front doors

inv-visibility reconcile --config sources.yaml for the scheduler, GET /v1/inventory/available?sku= for the dashboard. Exit code 2 when a critical exception exists, so the cron job alerts.
